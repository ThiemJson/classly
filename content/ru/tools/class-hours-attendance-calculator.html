Пример с 45 занятиями

Для курса из 45 занятий с целевым показателем 80% допустимое количество пропусков равно floor(45 × 20%) = 9 занятий. Если вы уже пропустили 3, у вас остаётся 6 занятий.

Когда каждое занятие состоит из 3 периодов, 6 оставшихся периодов равны 2 полных занятиям. Если продолжительность занятия отличается, обновите это поле, а не принимайте все занятия за одинаковые.

Используйте правильную единицу посещаемости

  1. Проверьте, учитывает ли ваше учебное заведение встречи, периоды или часы по часам.
  2. Введите полный курс в этой единице.
  3. Введите ту же единицу для каждого занятия и для уже пропущенного времени.
  4. Подтвердите вашу цель по текущим правилам курса.

Эта конверсия полезна, когда одна запись в расписании содержит несколько периодов. Официальная запись посещаемости должна определять, какую единицу использовать.
