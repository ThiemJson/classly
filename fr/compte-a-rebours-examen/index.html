Fonctionnement

Choisis la date officielle. Un examen demain est à un jour. Une semaine complète regroupe sept jours calendaires.

Désactive l'option si tu étudies le dimanche. Les autres jours fériés ne sont pas retirés automatiquement.

Créer ton plan

  1. Confirme le calendrier récent.
  2. Répartis les sujets entre les jours restants.
  3. Garde les derniers jours pour réviser.
  4. Utilise les rappels Classly.

Questions fréquentes

La date est-elle enregistrée ?

Non. Le calcul s'effectue dans cet onglet et la date n'est pas stockée.

Le jour de l'examen est-il compté ?

Oui. Le calcul va de demain à la date choisie ; aujourd'hui est le jour zéro.

Que change l'exclusion des dimanches ?

Seuls les jours d'étude changent ; les jours calendaires et semaines restent identiques.
