자주 묻는 질문

Classly 사용에 관한 빠른 답변입니다.

시작하기

100%가 아닌 현재 출석률부터 시작할 수 있나요?

네, 가능합니다.학기 중간에 Classly 사용을 시작하면, 앱은 설치 이후의 수업 기록만 알 수 있기 때문에 첫 수업의 출석률이 100%로 표시됩니다.실제 출석률을 반영하려면 지금까지의 출석 기록을 직접 입력해 주세요.

  1. 열기 인사이트(Insights) → 결석해도 될까? (라고 불리는 과목(Subjects) 이라고 부릅니다).
  2. 해당 과목을 찾아 다음을 누르세요. 출석 횟수 직접 수정(Update Counts Manually).이 기능을 사용하려면 Classly 3.2 버전 이상이 필요합니다. 보이지 않는다면 앱을 업데이트하세요.
  3. 입력하세요 진행된 수업 횟수 그리고 출석한 수업 횟수 (예: 40회 진행 중 26회 출석, 65%)
  4. 해당 총계에 오늘 수업이 포함되는지 여부를 선택한 다음, 다음을 누르세요. 저장.

Classly에 65%가 표시되며, 이후 수업을 기록할 때마다 수치가 업데이트됩니다.다음 수업에 출석하면 27/41(65.9%)이 되고, 결석하면 26/41(63.4%)이 됩니다. 결석해도 될까요? 목표치를 다시 달성하기 위해 연속으로 몇 번의 수업에 출석해야 하는지도 알려줍니다. 이 예시에서는 75%를 달성하려면 16번의 수업에 연속으로 출석해야 합니다.

현재 출석률만 알고 계신가요? 대학 포털이나 출석부에서 진행된 총 수업 횟수를 확인하세요.정확한 횟수를 알기 어렵다면, 예상 횟수에 출석률을 곱해 계산해 보세요(예: 총 40회 수업 × 65% = 26회 출석).

각 과목에 대해 이 과정을 반복하세요.학기 중간에 과목을 추가하는 경우, 시작일을 '오늘'로 설정할 수 있습니다. 그러면 해당 날짜 이전의 기록이 모두 반영됩니다.이렇게 반영된 날짜들은 캘린더에 고정되지만, 언제든지 다음 기능을 통해 되돌릴 수 있습니다. 수동으로 입력한 기록 삭제하기 (같은 화면에서 가능합니다.)

단계별 전체 가이드 읽기.

왜 출석률이 아닌 수업 횟수를 입력해야 하나요?

같은 출석률이라도 실제 의미는 크게 다를 수 있습니다.예를 들어 65%라는 수치는 '총 20회 수업 중 13회 출석'일 수도 있고, '총 100회 수업 중 65회 출석'일 수도 있습니다. 출석률을 75%까지 올리려면, 첫 번째 학생은 8회 연속으로 출석해야 하지만, 두 번째 학생은 40회나 출석해야 합니다.

실제 수업 횟수를 입력하면, Classly을 통해 앞으로 몇 번까지 결석해도 되는지, 혹은 몇 번 더 출석해야 하는지 정확히 확인할 수 있습니다.

시간표는 어떻게 추가하나요?

각 과목의 요일, 시간, 강의실 정보를 입력하여 과목을 추가하세요. 과목(Subjects) 이미 시간표 파일을 가지고 있다면, '과목(Subjects)' 탭 상단에 있는 '시간표 가져오기(Import Timetable)' 버튼을 눌러 JSON 또는 CSV 파일을 붙여넣거나 업로드하세요. 내용을 미리 확인한 후 가져올 수 있습니다.

안내 가이드를 다시 확인하고 싶다면 언제든지 '더 보기(More)' → '설정 가이드(Setup Guide)'.

과목마다 출석 목표를 다르게 설정할 수 있나요?

네, 가능합니다.각 과목은 고유한 출석 목표를 가지며, 과목을 추가하거나 수정할 때 설정할 수 있습니다.'인사이트(Insights)' 메뉴에서는 각 과목의 출석 현황을 해당 과목의 목표와 비교하여 보여줍니다.

학기 시작일이나 종료일은 어떻게 변경하나요?

날짜는 언제든지 변경할 수 있습니다.날짜를 변경해도 기존에 기록해 둔 데이터는 삭제되지 않습니다.

  1. 열기 인사이트(Insights) → 개요(Overview).
  2. 아래로 스크롤하여 다음을 탭하세요. 학기 설정(Semester Parameters).
  3. 탭하세요. 종료일(End Date) 그런 다음 새로운 날짜를 선택하세요.두 날짜를 모두 변경하려면 다음을 탭하세요. 시작일(Start Date): 시작일을 선택하면, Classly에서 종료일도 함께 묻습니다.

변경 사항은 즉시 저장되며, 출석률과 '결석 가능 횟수(Can I miss?)' 정보도 새로운 날짜에 맞춰 업데이트됩니다.

학기가 이미 종료되었나요? 개요(Overview) 화면 상단에 종료일 변경(Change End Date) 버튼이 표시됩니다.더 이후의 날짜를 선택하여 계속 기록을 관리하세요.

학기는 최대 1년까지 설정할 수 있습니다.새로운 학기를 시작하시나요? 그렇다면 다음 기능을 사용하세요. 새 학기 시작(Start New Semester) 이 기능을 사용하면 현재 과목과 출석 기록이 초기화됩니다.단, 기존 데이터는 다음 경로에 사본으로 저장됩니다. 더 보기(More) → 학기 백업(Semester Backup) → 이전 학기(Previous Semesters).

단계별 전체 가이드 읽기.

출석(Attendance)

출석률은 어떻게 계산되나요?

이는 전체 수업 횟수 대비 출석 또는 결석으로 표시한 수업 횟수를 나타냅니다.아직 표시하지 않은 수업, 취소된 수업, 그리고 휴일은 계산에서 제외됩니다.

직접 입력한 수업 횟수가 있다면, 해당 수치들은 전체 수업 횟수와 출석/결석 횟수 모두에 포함됩니다.

"결석해도 될까?(Can I miss?)"는 무엇을 알려주나요?

과목별로, 목표 출석률을 유지하면서 추가로 몇 번 더 결석할 수 있는지를 보여줍니다.만약 이미 목표치 아래로 떨어졌다면, 다시 목표치를 회복하기 위해 연속으로 몇 번의 수업에 출석해야 하는지를 알려줍니다.

탭하세요. 시뮬레이션 결정을 내리기 전에 향후 수업 상황을 미리 시뮬레이션해 볼 수 있습니다.

수업을 표시하는 것을 잊었거나 잘못 표시했습니다.어떻게 수정하나요?

메인 화면 상단의 달력 아이콘을 눌러 달력을 열고, 해당 날짜를 선택하여 수업을 변경하세요.출석 기록이 즉시 업데이트됩니다.

수동으로 입력한 기록이 있는 날짜는 잠겨 있습니다.이를 변경하려면 해당 과목의 수동 입력 기록을 수정하거나 삭제하세요.

수업이 취소되었거나 학교가 휴일인 경우 어떻게 해야 하나요?

수업을 '취소됨(Cancelled)'으로 표시하거나, '오늘(Today)' 또는 '달력(Calendar)' 화면에서 해당 날짜 전체를 '휴일(Holiday)' 로 설정하세요.이렇게 하면 출석 기록에 영향을 주지 않습니다.

추가 수업을 등록하거나 특정 날짜의 시간표를 변경하려면 어떻게 하나요?

달력을 열고 해당 날짜를 선택하세요.추가 수업을 등록하거나, 해당 날짜의 시간만 변경하거나, 다른 날의 시간표를 불러올 수 있습니다.기존의 정기 주간 시간표는 그대로 유지됩니다.

특정 날짜(과거 날짜 포함)부터 시간표가 변경되었습니다.이전 주의 기록은 그대로 둔 채 시간표를 업데이트하려면 어떻게 해야 하나요?

해당 과목을 열고 과목(Subjects) 탭에서 요일이나 시간을 변경한 다음, 변경 사항 저장을 누르세요.그러면 업데이트된 시간표 적용 시작일을 묻는 메시지가 나타납니다.새로운 시간표가 적용되기 시작한 날짜를 선택하세요(과거 날짜도 선택 가능합니다).

선택한 날짜 이전의 주차에는 기존 시간표와 이미 기록된 출석 정보가 그대로 유지되며, 해당 날짜부터는 새로운 시간표가 적용됩니다.시간표가 변경된 과목마다 이 과정을 반복하세요.

전체 시간표가 변경된 경우에는 다시 가져오기(re-import) 기능을 사용할 수도 있습니다. '시간표 가져오기(Import Timetable)' 그리고 적용 시작 날짜를 선택하세요.

특정 하루만 변경하려면 다음을 확인하세요. 수업을 추가하거나 특정 날짜의 시간표를 변경하려면 어떻게 해야 하나요?

알림

수업 알림을 받지 못하고 있어요.

확인 사항 더 보기 → 알림 첫째, 각 수업 전 알림과 출석 체크 알림을 켜거나 끌 수 있으며, 알림이 울릴 시점(수업 전 시간)을 설정할 수 있습니다.

또한 휴대폰 설정에서 Classly 앱의 알림이 허용되어 있는지 확인하세요.일부 안드로이드 휴대폰에서는 배터리 절전 기능으로 인해 알림이 지연될 수 있으므로, Classly 앱이 배터리 제한 없이 실행되도록 설정해 주세요.

데이터

Classly은 무료인가요?

네, 무료입니다.Google 캘린더 동기화 및 홈 화면 위젯을 포함한 모든 기능을 무료로 이용할 수 있으며, 광고도 없습니다.

계정이 필요하거나 인터넷 연결이 필요한가요?

아니요. Classly은 완전히 오프라인 상태에서 작동하며, 별도의 계정이 필요하지 않습니다.인터넷은 Google 캘린더 동기화를 사용할 때, 그리고 익명으로 오류 정보나 사용 데이터를 진단할 때만 사용됩니다.

Classly은 제 위치 정보를 사용하나요?

아니요. Classly은 위치 정보 접근 권한을 요청하지 않습니다.강의실과 건물 정보는 텍스트 형태로 저장됩니다.

데이터를 새 휴대폰으로 옮길 수 있나요?

네, 가능합니다. 가장 쉬운 방법은 Google 드라이브 백업을 이용하는 것입니다.앱을 열고 '더 보기' → '학기 백업'으로 이동한 뒤 다음 항목을 누르세요. 'Google 드라이브 연결'그러면 Classly은 모든 백업 데이터를 사용자의 Google 계정 내 숨겨진 폴더로 복사합니다. 이 폴더는 Classly에서만 확인할 수 있습니다.

새 휴대폰(Android 또는 iPhone)에 Classly을 설치하세요. 이전에 Classly을 사용한 적이 있나요?백업을 복원하세요. 시작 화면에서 'Drive에서 복원'을 선택하고 동일한 Google 계정으로 로그인하세요.

또한, '더 보기' → '학기 백업'으로 이동한 뒤에서 백업을 생성하여 파일을 안전한 곳에 저장한 뒤, 새 기기에서 불러올 수도 있습니다.이러한 백업 수단이 없는 상태에서 Classly 앱을 삭제하면 데이터가 모두 사라집니다(데이터는 휴대폰 내에만 저장되기 때문입니다).

'Google 캘린더 동기화(Google Calendar Sync)' 기능을 사용하면 Google 계정에 어떤 변화가 생기나요?

Classly 전용 캘린더가 하나 생성되며, 수업 일정이 해당 캘린더에 추가됩니다.사용자의 다른 캘린더는 읽거나 변경하지 않습니다. 이 기능은 다음 경로에서 활성화할 수 있습니다. '더 보기(More)' → 'Google 캘린더 동기화(Google Calendar Sync)'.
